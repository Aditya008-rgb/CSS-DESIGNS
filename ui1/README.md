# EduFlex – Modern E-Learning Landing Page

A clean, responsive landing page interface for **EduFlex**, an online education platform designed to connect learners with global tutors. Built from scratch focusing on modern CSS layout techniques and clean UI components.

## 🛠️ Built With

- **HTML5:** Semantic structure (`nav`, `header`, `section`, etc.)
- **CSS3:** 
  - CSS Flexbox & CSS Grid for asymmetric card alignment
  - Custom pill navigation & interactive call-to-action buttons
  - Responsive typography & subtle hover states
  - Modular color schemes and border-radius styling

---

## 💡 Key Features

- **Modern Hero Section:** Bold typography paired with an asymmetric multi-image showcase.
- **Pill Navigation & CTAs:** Smoothly curved border buttons and interactive states.
- **Key Stats Banner:** Highlight counters showcasing active students and tutor community metrics.
- **Zero Frameworks:** Pure vanilla HTML and CSS without external dependencies or component libraries.
